## 🌟 Project Overview

The **Bondska NDPS System** is a comprehensive digital preservation and learning platform for Västerbottnian dialect (Bondska), a North Swedish dialect spoken in the Västerbotten region. This system provides tools, data, and documentation for translating, learning, and understanding this historically significant dialect.

**What is Bondska?**
- Regional dialect spoken in Västerbotten, northern Sweden
- ~15,000 active speakers
- Preserves Old Norse linguistic features
- Culturally significant for Swedish heritage
- Modern initiative to preserve and revitalize

## 🗙️ Translation System: 4-Phase Learning

The system uses a scientifically-designed 4-phase approach to gradually introduce transformations:

### Phase 1: Pronoun Shift
- High-frequency word substitutions
- Examples: jag → ja, du → dö, inte → ikk
- **Duration:** 1 week
- **Difficulty:** Easy

### Phase 2: Vowel Shifts  
- Systematic vowel transformations
- Examples: a → å, o → u, e → ä
- **Duration:** 1-2 weeks
- **Difficulty:** Medium

### Phase 3: Apocope & Consonants
- Word ending changes and consonant rules
- Examples: -er deletion, sk → ʂ, final consonants preserved
- **Duration:** 1-2 weeks
- **Difficulty:** Hard

### Phase 4: Grammar & Fluency
- Advanced features and natural speech
- Grammar rules, tonal accents, regional variations
- **Duration:** 2+ weeks
- **Difficulty:** Expert

## 📊 Data Files Detail

### vocabulary.json (20+ words, scalable to 500+)

Each word entry contains:
```json
{
  "id": 1,
  "swedish": "hus",
  "bondska": "hus",
  "ipa": "[hʉːs]",
  "english": "house",
  "category": "noun",
  "phase": 1,
  "frequency": 5,  // 1-5 scale
  "notes": "No change needed"
}
```

**Sample words included:**
- Nouns: hus, kat, bok, träd
- Verbs: kan, gå, var, är
- Pronouns: jag, du, vi, de
- Particles: inte, och, eller

### rules.json (18+ transformation rules)

Each rule contains:
```json
{
  "id": "p1_pronoun_jag",
  "name": "First person singular pronoun",
  "phase": 1,
  "pattern": "\\bjag\\b",  // Regex pattern
  "replacement": "ja",
  "explanation": "Swedish 'jag' (I) becomes 'ja'",
  "examples": ["Jag heter Alex" → "ja héter Alex"],
  "exceptions": "None - consistent"
}
```

**Rules by phase:**
- Phase 1: 7 pronoun/negation rules
- Phase 2: 5 vowel transformation rules
- Phase 3: 4 apocope/consonant rules
- Phase 4: 2 grammar/fluency rules

### examples.json (20+ example translations)

Each example contains:
```json
{
  "id": 1,
  "swedish": "Hej, jag heter Alex",
  "bondska": "Hej, ja héter Alex",
  "english": "Hi, my name is Alex",
  "phase": 1,
  "category": "greeting",
  "rules": ["jag → ja"]
}
```

**Categories included:**
- Greetings
- Questions
- Statements
- Negations
- Possessions
- Descriptions
- Complex sentences
