# 📤 Bondska Example Translations
## 50+ Real-World Translation Examples

---

## Overview

This document provides example translations from Standard Swedish to Bondska, organized by:
- **Learning Phase** (1-4)
- **Category** (greetings, conversation, sentences, etc.)
- **Complexity** (simple to advanced)

Each example shows:
- **Swedish**: Standard Swedish version
- **Bondska**: Bondska dialect version
- **English**: English translation
- **Phase**: Which learning phase applies
- **Rules**: Which transformation rules are used

## 👋 Phase 1 Examples: Pronoun Shift

### Greetings & Introductions

**1. Simple Greeting**
```
Swedish:  Hej, jag heter Alex
Bondska:  Hej, ja héterÅlex
English:  Hi, my name is Alex
Phase:    1
Rules:    jag → ja (pronoun shift)
```

**2. Response**
```
Swedish:  Du är välkommen
Bondska:  Dö är välkömmen
English:  You are welcome
Phase:    1
Rules:    du → dö (pronoun shift)
```

**3. Meeting Question**
```
Swedish:  Vad heter du?
Bondska:  Vatt héter dö?
English:  What is your name?
Phase:    1
Rules:    vad → vatt, du → dö
```

### Basic Statements

**4. Subject + Verb**
```
Swedish:  Jag går
Bondska:  Ja gå
English:  I go / I'm going
Phase:    1
Rules:    jag → ja, går → gå (apocope)
```

**5. Plural Subject**
```
Swedish:  Vi går här
Bondska:  Vó gå här
English:  We go here
Phase:    1
Rules:    vi → vó, går → gå (apocope)
```

**6. Third Person Plural**
```
Swedish:  De går inte
Bondska:  Dö gå ikk
English:  They do not go
Phase:    1
Rules:    de → dö, går → gå, inte → ikk
```

### Possession

**7. Simple Possession**
```
Swedish:  Min hund
Bondska:  Mín hund
English:  My dog
Phase:    1
Rules:    min → mín (vowel shift)
```

**8. Possessive Sentence**
```
Swedish:  Min far är här
Bondska:  Mín far är här
English:  My father is here
Phase:    1
Rules:    min → mín
```

**9. Multiple Possessives**
```
Swedish:  Din mor och min far
Bondska:  Dín mör och mín far
English:  Your mother and my father
Phase:    1
Rules:    din → dín, min → mín
```

### Negation

**10. Simple Negation**
```
Swedish:  Jag inte kan
Bondska:  Ja ikk kan
English:  I cannot
Phase:    1
Rules:    jag → ja, inte → ikk
```

**11. Past Tense Negation**
```
Swedish:  Han var inte här
Bondska:  Han vär ikk här
English:  He was not here
Phase:    1 + 2
Rules:    var → vär (vowel shift), inte → ikk
```

**12. Plural Negation**
```
Swedish:  De inte går
Bondska:  Dö ikk gå
English:  They do not go
Phase:    1
Rules:    de → dö, inte → ikk, går → gå
```

### Questions

**13. Who Question**
```
Swedish:  Vem är du?
Bondska:  Vem är dö?
English:  Who are you?
Phase:    1
Rules:    du → dö
```

**14. Where Question**
```
Swedish:  Var är du?
Bondska:  Vär är dö?
English:  Where are you?
Phase:    1 + 2
Rules:    var → vär (vowel shift), du → dö
```

**15. How Question**
```
Swedish:  Hur går det?
Bondska:  Húr gå dett?
English:  How are you? / How is it going?
Phase:    1 + 3
Rules:    hur → húr, går → gå, det → dett (consonant preservation)
```

English:  I have a night

Rules:    jag → ja, a → å

**18. Before /r/**

Bondska:  Mín kår

## 퉰d️ Phase 3 Examples: Apocope & Consonants

### Apocope: Dropping -ER

**26. Plural Noun**
```
Swedish:  hundar
Bondska:  hundar (or hundar)
English:  dogs
Phase:    3
Rules:    -ar may be dropped or reduced
```

**27. Present Tense**
```
Swedish:  Han gåer
Bondska:  Han gå
English:  He goes
Phase:    3
Rules:    -er dropped from verb
```

**28. Complex Apocope**
```
Swedish:  Vi springer
Bondska:  Vó spring
English:  We run
Phase:    1 + 3
Rules:    vi → vó, -er apocope
```

### Final Consonant Preservation

**29. Word Final -D**
```
Swedish:  ord
Bondska:  uɔrd
English:  word
Phase:    3
Rules:    D pronounced at word end
```

**30. Word Final -T**
```
Swedish:  et (silent in Swedish)
Bondska:  ett (pronounced)
English:  it / the
Phase:    3
Rules:    T pronounced at word end
```

### Consonant Softening

**31. T + Front Vowel**
```
Swedish:  tio
Bondska:  tjo
English:  ten
Phase:    3
Rules:    t → tj before i
```

**32. Complex with Softening**
```
Swedish:  Jag tio
Bondska:  Ja tjo
English:  I (have) ten
Phase:    1 + 3
Rules:    jag → ja, t → tj
```

### SK Retroflexion

**33. Ska (shall)**
```
Swedish:  ska
Bondska:  ʂa
English:  shall
Phase:    3
Rules:    sk → ʂ
```

**34. Ska in Sentence**
```
Swedish:  Vi ska gå
Bondska:  Vó ʂa gå
English:  We shall go
Phase:    1 + 3
Rules:    vi → vó, sk → ʂ
```

### Combined Phases 1-3

**35. Full Transformation**
```
Swedish:  Jag kan inte se en stor bok
Bondska:  Ja kan ikk sä en stör buk
English:  I cannot see a big book
Phase:    1 + 2 + 3
Rules:    Multiple: jag → ja, ante → ikk, e → ä, o → ö, o → u
```

**36. Question with All Phases**
```
Swedish:  Vad går du?
Bondska:  Vatt gå dö?
English:  What are you doing?
Phase:    1 + 2 + 3
Rules:    vad → vatt, går → gå, du → dö
```

## 🌟 Phase 4 Examples: Grammar & Fluency

**37. Weak Past**
```
Swedish:  Jag gick
Bondska:  Ja gåck
English:  I went
Phase:    1 + 2 + 4
Rules:    jag → ja, gick → gåck (vowel shift + apocope)
```

**38. Past Tense Sentence**
```
Swedish:  Vi var inte här
Bondska:  Vó vär ikk här
English:  We were not here
Phase:    1 + 2 + 4
Rules:    vi → vó, var → vär, inte → ikk
```

**39. Multiple Past Events**
```
Swedish:  Jag gick och han stannade
Bondska:  Ja gåck och han stannate
English:  I went and he stayed
Phase:    1 + 2 + 4
Rules:    Conjugation patterns
```

**41. Neuter**
