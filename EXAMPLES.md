# 📤 Pitemål Translation Examples
## 50+ Real-World Translation Examples for Piteå Dialect

---

## Overview

This document provides authentic translation examples from Standard Swedish to Pitemål (Pite Bondska), aligned with the project's rule-based engine.

**Key Features Demonstrated:**
*   **Apocope:** Dropping final vowels (e.g., *kasta* → *kaast*)
*   **Thick L:** Retroflex L sound (e.g., *bord* → *boL*)
*   **Plural Verbs:** Distinct verb forms for plural subjects (e.g., *vi kommer* → *ve kåma*)
*   **Vowel Shifts:** *a* → *å*, *o* → *u*

## 👋 Phase 1: Basic Conversation

### Greetings & Pronouns

**1. Simple Introduction**
```
Swedish:  Hej, jag heter Alex
Pitemål:  Heddu, I hät Alex
English:  Hi, my name is Alex
Rules:    jag → I, heter → hät (apocope)
```

**2. Where are you from?**
```
Swedish:  Var kommer du från?
Pitemål:  Vors kåm dö frå?
English:  Where do you come from?
Rules:    var → vors, kommer → kåm, du → dö, från → frå
```

**3. Plural Subjects (The "We" Rule)**
```
Swedish:  Vi kommer från Piteå
Pitemål:  Ve kåma frå Pite
English:  We come from Piteå
Rules:    vi → ve, kommer → kåma (plural verb -a suffix)
```

## 💧 Phase 2: Vowel Shifts & Morphology

### The "Thick L" Rule

**4. The Table**
```
Swedish:  Bordet är stort
Pitemål:  BoLe jär stort
English:  The table is big
Rules:    bordet → boLe (Thick L, definite suffix -e)
```

**5. Hard Work**
```
Swedish:  Det är hårt arbete
Pitemål:  Hä jär håLt arbet
English:  It is hard work
Rules:    det → hä, hårt → håLt (Thick L)
```

### Apocope (Vowel Dropping)

**6. School**
```
Swedish:  Jag går i skola
Pitemål:  I gå i skåoL
English:  I go to school
Rules:    skola → skåoL (Strong apocope), går → gå
```

**7. Speaking**
```
Swedish:  Hon brukar prata
Pitemål:  Ho bruk pråta
English:  She usually talks
Rules:    hon → ho, brukar → bruk (apocope), prata (infinitive often keeps -a)
```

## 📜 Advanced Text Examples

### Technology Text (Snippet)

**Swedish:**
"Teknologin har förändrat vårt samhälle. Det är svårt att förstå."

**Pitemål:**
"Teknologin ha förändra wåLt samhälle. Hä jär svåLt at förstå."

**Breakdown:**
*   *har* → *ha* (singular/general aux)
*   *vårt* → *wåLt* (Thick L)
*   *det* → *hä*
*   *är* → *jär*
*   *att* → *at*

### Daily Life

**Swedish:**
"Jag läser en bok och dricker kaffe."

**Pitemål:**
"I läs en båok å drick kaffe."

**Breakdown:**
*   *läser* → *läs* (present tense apocope)
*   *bok* → *båok* (vowel shift)
*   *och* → *å*
*   *dricker* → *drick* (present tense apocope)
