## General Principles

### Why Use IPA?
- **Precision**: Captures exact pronunciation regardless of orthography
- **Universality**: Understood by linguists worldwide
- **Consistency**: Same symbol always represents the same sound
- **Comparison**: Enables cross-dialect analysis

### Basic Conventions
1. **Square brackets** `[]` for phonetic transcription (precise sounds)
2. **Slashes** `//` for phonemic transcription (meaningful sound distinctions)
3. **Stress** marked with `ˈ` before stressed syllable
4. **Length** marked with `:` after vowel (long vowel)
5. **Tones** indicated with diacritics or separate notation

### Retroflex Consonants (Nordic-Specific)

**Critical for Northern Dialects**

| IPA | Swedish Spelling | Description | Example |
|-----|------------------|-------------|---------|
| [ɖ] | rd | Retroflex plosive | bo**rd** [buːɖ] |
| [ʈ] | rt | Retroflex plosive | ko**rt** [kuːʈ] |
| [ɭ] | rl | Retroflex lateral | ka**rl** [kɑːɭ] |
| [ɳ] | rn | Retroflex nasal | ba**rn** [bɑːɳ] |
| [ʂ] | rs | Retroflex fricative | La**rs** [lɑːʂ] |

**Thick L**: In some dialects, retroflex [ɭ] is pronounced as a distinct "thick L" sound, fundamental to dialect identity (especially Pitemål/Bondska).

## Suprasegmentals

### Length
- **Vowel length**: `ː` after vowel
  - Long: [aː], Short: [a]
- **Consonant length** (gemination): `ː` after consonant
  - Geminate: [tː], Single: [t]

### Stress
- **Primary stress**: `ˈ` before syllable
  - Example: **pap**per [ˈpapːɛr]
- **Secondary stress**: `ˌ` before syllable (if needed)
  - Example: **bio**logi [ˌbiːoloˈɡiː]

### Tonal Accent (Swedish-Specific)

Swedish has two tonal accents (pitch patterns):

1. **Accent 1 (Acute)**: Single peak
   - Example: **an**den (the duck) [ˈandɛn] with high pitch on first syllable
   
2. **Accent 2 (Grave)**: Double peak  
   - Example: **an**den (the spirit) [ˈandɛn] with high-low-high pattern

**Note**: Tonal accent is often not marked in basic IPA transcription but is crucial for meaning distinction in Swedish.

## Dialect-Specific Features

### Apocope (Vowel Dropping)
Document final vowel deletion:
- Swedish: tala [ˈtɑːla]
- Dialect: tal [tɑːl]

### Diphthongization
Show vowel changes:
- Swedish: sten [steːn]
- Dialect: stein [steɪn]

### Retroflexion Patterns
Specify how r-combinations are realized:
- Standard: bord [buːɖ]
- Thick L dialect: boL [buːɭ]

## Documentation Format

### For Vocabulary Entries

```json
{
  "word": "stein",
  "ipa": "[steɪn]",
  "swedish": "sten",
  "pronunciation_notes": "Diphthong [eɪ] from Old Norse 'steinn'"
}
```

### For Alphabet Guides

```markdown
## E - Short E Sound

**IPA**: [ɛ] (short), [eː] (long)

**Description**: Close-mid front unrounded vowel

**Examples**:
- ben [beːn] (leg) - long
- bett [bɛtː] (bite) - short

**Dialect Variation**: Often diphthongized to [eɪ] in northern dialects
```

### For Phonetic Rules

```markdown
### Rule: E → EI Diphthongization

**Pattern**: Short /e/ in stressed syllables

**Change**: [ɛ] → [eɪ]

**Examples**:
- sten [steːn] → stein [steɪn]
- hem [heːm] → heim [heɪm]
```

## Best Practices

### Do:
- ✅ Use IPA consistently throughout all documentation
- ✅ Provide both narrow (detailed) and broad (simplified) transcriptions when helpful
- ✅ Include audio examples when possible
- ✅ Document exceptions and variations
- ✅ Link to dialect-specific pronunciation guides

### Don't:
- ❌ Mix IPA with non-standard phonetic notation
- ❌ Use approximate spellings instead of IPA
- ❌ Omit important phonetic details
- ❌ Use deprecated IPA symbols
- ❌ Forget to indicate vowel length
