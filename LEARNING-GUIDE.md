# 🎓 Bondska Learning Guide
## 4-Phase Mastery System for Västerbottnian Dialect

---

## 💼 Overview

This guide walks you through learning Bondska using a structured 4-phase progression:

1. **Phase 1** (Week 1): Pronoun Shift - Learn basic word substitutions
2. **Phase 2** (Week 2): Vowel Shifts - Master phonetic transformations
3. **Phase 3** (Week 3): Apocope & Consonants - Handle word endings
4. **Phase 4** (Week 4+): Grammar & Fluency - Advanced features

Each phase builds on the previous one. You can learn at your own pace, but the order is important.

---

## 🗓️ How to Use This Guide

### For Learners
1. Read the phase explanation
2. Study the key transformations
3. Complete the practice exercises
4. Use the web translator to test your knowledge
5. Move to the next phase when comfortable

### For Teachers
1. Each phase is ~1 week of instruction
2. Teach the key rules first
3. Have students practice with examples
4. Test understanding before moving forward
5. Use the web app as a learning tool

### Time Commitment
- **Phase 1**: 3-5 hours
- **Phase 2**: 4-6 hours
- **Phase 3**: 5-7 hours
- **Phase 4**: Ongoing (open-ended)
- **Total**: 20+ hours for competency

## 🔢 Phase 1: Pronoun Shift (Week 1)
### Master High-Frequency Word Substitutions

### Goal
Learn basic word substitutions so you can transform simple Swedish sentences into Bondska automatically.

### Key Concept
Phase 1 is about **replacing common pronouns and basic words**. This gives you immediate results and provides the foundation for everything else.

### The Transformations

#### Pronouns

**1st Person**
```
Swedish  →  Bondska
jag      →  ja         (I)
mig      →  mej        (me)
mig      →  mejaj      (myself - emphatic)
```

**2nd Person**
```
du       →  dö         (you - singular)
dig      →  dej        (you - singular object)
```

**3rd Person**
```
han      →  han        (he - no change)
hon      →  hon        (she - no change)
den      →  dén        (it - shortened)
de       →  dö         (they)
```

**Plural**
```
vi       →  vó         (we)
ni       →  nó         (you - plural)
de       →  dö         (they)
```

#### Basic Verbs

**To Be (vara/är)**
```
är      →  är         (is/am/are - no change)
var      →  vär        (was - vowel shift)
vara     →  väræ       (to be - vowel shift)
```

**To Go (gå)**
```
gå       →  gå         (go - no change)
går      →  gå         (goes - apocope)
gick     →  gåck       (went - vowel shift)
```

**Negation**
```
inte     →  ikk        (not)
ej       →  äj         (no)
nej      →  näj        (no)
```

#### Possessive Pronouns

```
min      →  mín        (my)
din      →  dín        (your)
vår      →  vår        (our - no change)
er       →  ér         (your plural)
```

#### Question Words

```
vem      →  vem        (who - no change)
vad      →  vatt       (what)
var      →  vär        (where)
när      →  när        (when - no change)
hur      →  húr        (how)
varför   →  varför     (why)
```

### Practice Exercises

#### Exercise 1.1: Simple Pronouns
Translate these Swedish sentences to Bondska using only pronoun rules:

1. Swedish: "Jag heter Alex"
   Bondska: ?
   Answer: "ja héter Alex"

2. Swedish: "Du är här"
   Bondska: ?
   Answer: "dö är här"

3. Swedish: "Vi går här"
   Bondska: ?
   Answer: "vó gå här"

4. Swedish: "De är inte här"
   Bondska: ?
   Answer: "dö är ikk här"

5. Swedish: "Han var här"
   Bondska: ?
   Answer: "han vär här"

#### Exercise 1.2: Possessive Pronouns
Translate using possessive rules:

1. "Min hund" → "mín hund" (my dog)
2. "Din bror" → "dín bror" (your brother)
3. "Vår hus" → "vår hus" (our house)
4. "Er dotter" → "ér dotter" (your daughter)
5. "Min far och din mor" → "mín far och dín mör"

#### Exercise 1.3: Mixed Sentences
Combine multiple Phase 1 rules:

1. "Jag och du går"
   Answer: "ja och dö gå"

2. "Vi inte kan"
   Answer: "vó ikk kan"

3. "Min mor är här"
   Answer: "mín mör är här"

4. "Vad heter du?"
   Answer: "vatt héter dö?"

5. "De var inte här"
   Answer: "dö vär ikk här"

### Practice Tips

- **Repetition is key**: Say each transformation 5-10 times aloud
- **Create cards**: Write Swedish on one side, Bondska on the other
- **Test yourself**: Use the web translator to check your answers
- **Natural speech**: Once you know the rules, try speaking naturally
- **Common mistakes**: Don't overthink - just apply the rules consistently

### How to Know You've Mastered Phase 1

- [ ] You can automatically transform all pronouns
- [ ] You recognize all question words in Bondska
- [ ] You can handle "inte" → "ikk" negation
- [ ] You feel comfortable with basic verb forms
- [ ] You can translate simple sentences without thinking
- [ ] You can speak simple Phase 1 sentences naturally

## 💧 Phase 2: Vowel Shifts (Week 2)
### Master Phonetic Transformations

### Goal
Learn how vowels change in Bondska, reflecting Old Norse pronunciation patterns.

### Key Concept
Bondska vowels shift in predictable ways:
- **a → å**: Open front becomes open back rounded
- **e → ä**: Close-mid front opens to open-mid front
- **o → u**: Mid back closes
- **ö → ô**: Front rounded lowers

These shifts are **phonetic** (sound-based) rather than spelling-based.

### The Transformations

#### A → Å Shift

**Pattern**: Open front /a/ → Open back /å/

**When**: In stressed syllables, especially before /r/

**Examples**:
```
kat   → kåt  (cat)
kar   → kår  (beloved)
nat   → nåt  (night)
bar   → bår  (carries)
fast  → fåst (fixed)
```

**Exceptions**:
- Some words preserve /a/
- Initial position sometimes variable
- Before fricatives: unpredictable

#### E → Ä Shift

**Pattern**: Close-mid front /e/ → Open-mid front /ä/

**When**: In open syllables (no consonant after)

**Examples**:
```
le    → lä    (smile)
se    → sä    (see)
met   → mät   (meet)
red   → räd   (afraid)
```

**Exceptions**:
- In final position: often preserved as /e/
- Before stops: sometimes preserved

#### O → U Shift

**Pattern**: Mid back /o/ → Close back /u/

**When**: In stressed syllables

**Examples**:
```
bok   → buk   (book)
ort   → urt   (place)
kost  → kust  (cost)
mot   → mut   (against)
```

**Exceptions**:
- Before velars: variable
- Initial position: often preserved
- Some words resist shift

#### Ö → Ô Shift

**Pattern**: Open-mid front /ö/ → Open back /ô/

**Examples**:
```
söck  → sôck  (search)
kör   → kôr   (run)
för   → fôr   (for)
ör    → ôr    (ear)
```

#### Vowel Lengthening

**Pattern**: Short vowels → Long vowels [Vː]

**Examples**:
```
mat   → måt   (food) - also lengthened [måːt]
bad   → båd   (bath) - [båːd]
```

#### Exercise 2.1: A → Å Shift

**Answers**: kår, nåt, fåst, bår, måsk

#### Exercise 2.2: E → Ä Shift

1. le → ?

3. met → ?

5. bed → ?

**Answers**: lä, sä, mät, räd, bäd

#### Exercise 2.3: O → U Shift

1. bok → ?
2. mot → ?
3. kot → ?

5. kort → ?

**Answers**: buk, mut, kut, kust, kurt

#### Exercise 2.4: Combined Phase 1 + Phase 2

1. "Jag var glad" → ?
   Answer: "ja vär glåd"

2. "Du har en bok" → ?
   Answer: "dö hår en buk"

3. "Vi se en kat" → ?
   Answer: "vó sä en kåt"

4. "Min mor leker" → ?
   Answer: "mín mör läker"

5. "De inte kan se" → ?
   Answer: "dö ikk kan sä"

### Practice Tips

- **Sound-based thinking**: Don't memorize letter patterns - think about sounds
- **Say it out loud**: Vowel shifts are about pronunciation
- **Listen to native speakers**: Hear the vowel changes in natural speech
- **Regular review**: Vowel shifts take time to internalize
- **Minimal pairs**: Practice pairs like bok/buk to hear the difference

### How to Know You've Mastered Phase 2

- [ ] You can identify all five main vowel shifts
- [ ] You apply vowel shifts automatically in speech
- [ ] You recognize vowel shifts in native Bondska
- [ ] You understand why vowels change (historical reasons)
- [ ] You can handle exceptions and variations
- [ ] You combine Phase 1 + Phase 2 smoothly
- [ ] You're starting to "sound" like a Bondska speaker

## 퉰d️ Phase 3: Apocope & Consonants (Week 3)
### Master Word Endings and Consonant Changes

### Goal
Learn how word endings change and consonants shift, allowing you to speak in complete sentences.

### Key Concept
Bondska:
- **Drops weak endings** (apocope)
- **Preserves final consonants** unlike Swedish
- **Softens consonants** before front vowels

### The Transformations

#### Apocope: -ER Suffix Deletion

**Pattern**: `-er` → `-` or `-är`

**Examples**:
```
katter  → katt  (cats)
hundar  → hundar (dogs - less common)
gåer   → gå    (goes)
```

**When**:
- Plural nouns: usually dropped
- Verb present tense: often dropped
- Depends on position and stress

#### Final Consonant Retention

Unlike Swedish, Bondska pronounces final consonants:

**-D Final**
```
ord  → uɔrd  (word) - D pronounced
fod  → fôd   (fed) - D pronounced
```

**-T Final**
```
att  → att   (that) - T pronounced
let  → lét   (let) - T pronounced
set  → sét   (seen) - T pronounced
```

#### Consonant Softening (Palatalization)

**T + Front Vowel → [tj]**
```
tio   → tjo   (ten)
tie   → tje   (nothing)
```

**D + Front Vowel → [dj]**
```
djur  → djúr  (animal)
```

**N + Front Vowel → [nj]**
```
nickel → njickl (nickel)
```

#### Consonant Cluster Changes

**SK → ʂ (Retroflexed)**
```
ska   → ʂa   (shall)
ski   → ʂi   (ski)
skina → ʂina (shine)
```

**ND Simplification**
```
land  → lan   (country) - D often dropped
```

**NG Preservation**
```
lång  → lång  (long) - unchanged
strang → strang (strong) - unchanged
```

#### Exercise 3.1: Apocope

#### Exercise 3.3: Consonant Softening

**Answers**: tjo, djúr, njickl

#### Exercise 3.4: Combined Phase 1-3

   Answer: "ja fär en buk" (I get a book)

2. "Du går till skolan"
   Answer: "dö gå till ʂölan"

   Answer: "katt spring" (cats run)

4. "Vi inte kan se det"
   Answer: "vó ikk kan sä dett" (We cannot see it)

### Practice Tips

- **Listening is crucial**: Hear native speakers drop endings
- **Practice rhythm**: Apocope changes sentence rhythm
- **Final consonants**: Emphasize pronunciation of word-final D, T
- **Softening patterns**: Becomes automatic with practice
- **Read aloud**: Helps internalize the patterns

### How to Know You've Mastered Phase 3

- [ ] You drop -ER endings automatically
- [ ] You pronounce final consonants clearly
- [ ] You handle consonant softening naturally

- [ ] You can speak complete sentences in Bondska

## 🌟 Phase 4: Grammar & Fluency (Week 4+)
### Advanced Features and Natural Speech

### Goal
Achieve fluency and comfortable natural speech in Bondska, including advanced grammar.

### Key Concept
Phase 4 is about:
- **Grammar details**: Gender, cases, tenses
- **Natural speech patterns**: Intonation, rhythm, idioms
- **Regional variations**: Different areas of Västerbotten
- **Archaic features**: Old Norse remnants
- **Internal monologue**: Thinking in Bondska

### Advanced Topics

#### Gender System

Bondska distinguishes gender in articles and adjectives:

**Masculine**: "en håst" (a horse)
**Feminine**: "en häst" (a mare - archaic)
**Neuter**: "ett hus" (a house)

#### Tonal Accents

Two word tones affect meaning:

**Accent 1** (single peak): Simple words
- "kå" (cat) - rising-falling

**Accent 2** (double peak): Compound words
- "kåtor" (cats) - rising-falling-rising

#### Dative Case (Location)

Some words take dative case for location/direction:

```
högan  → högan  (to the hill)
husan  → husan  (to the house)
```

#### Verb Tenses

**Present**: Simple present (Phase 3)
**Past**: -ade/-ede past (vowel shifts apply)
**Perfect**: "ha" + participle
**Progressive**: "vara" + present participle

### Practice Exercises

#### Exercise 4.1: Gender Agreement

   Answer: "en stôr höst" (masculine)

2. "___ stort hus" (a big house)
   Answer: "ett stört hus" (neuter)

#### Exercise 4.2: Dative Case
Form dative for location:

1. "Jag går ___" (I go to the house)
   Answer: "ja gå husan"

#### Exercise 4.3: Past Tense
Form past tense with vowel shifts:

1. "Jag gick" (I went)
   Answer: "ja gåck"

2. "Vi var" (We were)
   Answer: "vó vär"

#### Exercise 4.4: Conversation
Have simple conversations:

**Greeting**:
- "Húr går det?" (How are you?)
- "Må dét väll" (It's going well)

**Meeting Someone**:
- "Vem är du?" (Who are you?)
- "Ja héter Alex" (I'm called Alex)
- "Vart kom du från?" (Where are you from?)
- "Ja kom från Umeå" (I'm from Umeå)

### Practice Tips

- **Immersion**: Listen to Bondska media regularly
- **Speaking practice**: Talk to native speakers if possible
- **Shadowing**: Repeat native speakers' pronunciations
- **Content consumption**: Read Bondska literature
- **Think in Bondska**: Translate your thoughts naturally
- **Embrace variation**: Different speakers have different styles

- [ ] You think in Bondska automatically

- [ ] You understand Bondska media (videos, audio)
