## 📋 Overview

**Bondska** is a vibrant, living dialect spoken in Västerbotten in Northern Sweden. Unlike many endangered Nordic dialects, Bondska maintains strong community usage and cultural significance. This branch provides comprehensive tools and resources for learning, teaching, and preserving this precious linguistic heritage.

### What is Bondska?
- **Geographic origin**: Västerbotten region (particularly Bohuslän Coast)
- **Speakers**: ~15,000 active speakers (relatively healthy)
- **Classification**: North Swedish dialect group
- **Relationship to Swedish**: Distinct phonetics, grammar, vocabulary while maintaining mutual intelligibility
- **Cultural status**: Strong presence in local communities, media, and education

### Mission
Bondska is a **living language** that needs active documentation and teaching resources to ensure its survival for future generations.

## 🛠️ Tools & Resources

### 1. **Interactive Web Translator**

📄 **File**: `bondska-translator.html`

Open directly in any web browser (no installation needed).

**Features**:
- ✅ Real-time bidirectional translation (Swedish ↔ Bondska)
- ✅ 4 integrated tabs: Translator, Alphabet, Vocabulary, Learning
- ✅ Offline functionality
- ✅ Mobile-responsive design
- ✅ Dark mode support

### 2. **Command-Line Tool**

📄 **File**: `bondska-cli.py`

Python 3.8+ required.

**Features**:
- ✅ Interactive & batch translation modes
- ✅ Translation history tracking
- ✅ Alphabet display with IPA phonetics
- ✅ Vocabulary lookup
- ✅ Learning system integration

**Usage**:
```bash
python3 bondska-cli.py translate "Jag heter Alex"
python3 bondska-cli.py alphabet
python3 bondska-cli.py lookup "hus"
```

## 🎓 The 4-Phase Learning System

### **Phase 1: Pronoun Shift** (Week 1)
- Replace main pronouns (jag → ja, du → dö)
- Learn basic negation and verbs
- Goal: Automatic substitution

### **Phase 2: Vowel Shifts** (Week 2)
- Diphthongization (restore Old Norse sounds)
- Vowel darkening patterns
- Goal: Recognize vowel transformation rules

### **Phase 3: Apocope & Consonants** (Week 3)
- Word-ending omission
- Consonant softening
- Goal: Build complete sentences

### **Phase 4: Grammar & Fluency** (Week 4+)
- Gender system (Han/Hon/He)
- Dative case and location markers
- Goal: Internal monologue in Bondska
